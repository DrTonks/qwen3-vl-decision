# 五模型多维性能对比

2026-10-16。基于已完成的同一份 128 条合成开发集、32 个场景组和相同业务政策离线汇总。本次新增统计没有调用 Jev API，也没有重新运行模型。训练后两款 Qwen 均选各自完整训练中动作准确率最高的 step 1673，不拼接其他检查点的单项成绩。

**当前结论：训练后 0.8B 的任务适配质量和本地请求延迟最好，但仍未通过全部业务门槛。** 它比 Jev 的动作准确率高 9.38 个百分点，人工召回率却同为 88.89%，并有 1.82% 误拒绝。Jev 没有误拒绝，但存在 6.25% 的未认证调用工具错误率。保留默认服务与后端保护，继续验证；本表不等于上线批准。

比率统一以百分比表示，耗时使用毫秒；↑ 越高越好，↓ 越低越好。耗时与触发工具比例没有统一的优劣方向：后者取决于是否正确理解业务。

## 比较边界与复现

- 开发集参与了检查点选择，不能视为独立最终测试；数据为合成业务样本，不是线上用户流量。当前服务、规划检索、登录前状态应分别看，不能只看总体排名。
- Qwen 经过任务微调，Jev 根据给定政策零样本决策；编码、候选表示及计时环境不同。本地 GPU 为 RTX 4060 Laptop，Jev 使用 7890 代理且计入网络。这不是通用模型排行榜，也不是纯模型计算效率或并发负载测试。
- Jev 依实际 choice 评分；唯一 choice/概率不一致的样本按严格失败口径计分后，总准确率不变。传输重试、实际版本、用量和异常详见[报告72](72-Jev代理补测与请求恢复.md)。
- 未测或不可公平比较的显存、显卡利用率、并发吞吐、供应商实际费用、线上端到端完成率不填估计值。概率未做独立校准，本表不把置信度直接当正确率。
- 分母和来源散列见[汇总 JSON](evidence/financial-five-model-comparison-v1/summary.json)与[来源清单](evidence/financial-five-model-comparison-v1/sources.json)。公开证据包含五款模型逐条决策与耗时，可在新克隆中离线重算，不依赖本地权重、密钥或被忽略的 results 目录。
