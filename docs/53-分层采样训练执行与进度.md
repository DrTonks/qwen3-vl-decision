## 启动、进度、暂停和恢复

在qwen仓库根目录运行，环境、日志和检查点均位于D盘工作区。正式训练只在匹配探针及独立执行复核通过后启动；已有实验不会被同一启动命令覆盖。

```powershell
# 首次正式启动（已在运行时不要重复执行）
.\scripts\start-financial-sampling.ps1

# 查看进度；--watch持续显示，Ctrl+C仅退出查看器
.\.venv-qwen35\Scripts\python.exe -m qwenlab.financial_sampling_cycle progress
.\.venv-qwen35\Scripts\python.exe -m qwenlab.financial_sampling_cycle progress --watch

# 安全暂停：等待命令确认检查点完整、训练进程退出且可以关机
.\scripts\pause-financial-sampling.ps1

# 下次恢复，同一清单游标继续，不重新洗牌
.\scripts\resume-financial-sampling.ps1
```

探针专用命令如下，不能替代正式训练。`-PauseAtStep12`只在首次探针启动使用：uniform第12步保存退出，随后验证暂停并恢复到第13步。

```powershell
.\scripts\start-financial-sampling.ps1 -Probe -PauseAtStep12
.\.venv-qwen35\Scripts\python.exe -m qwenlab.financial_sampling_cycle progress --probe
.\scripts\pause-financial-sampling.ps1 -Probe
.\scripts\resume-financial-sampling.ps1 -Probe
```

启动器以隐藏进程运行，两个命名空间共用启动保护和GPU锁。不要使用任务管理器强杀来代替安全暂停。进度中的保存状态本身不表示可以关机，暂停脚本必须同时确认`worker_alive=false`、`safe_to_shutdown=true`且状态为paused或complete。

结果位置：正式`results/financial-sampling-v1/`，探针`results/financial-sampling-probe-v1/`；检查点在`.local/checkpoints/`对应命名空间；启动日志位置见`.local/financial-sampling-main-launch.json`或`.local/financial-sampling-probe-launch.json`。这些运行产物已加入gitignore，不上传大模型、优化器状态或本地日志。
