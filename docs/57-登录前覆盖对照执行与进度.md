- 单个新候选`preauth`，官方`Qwen/Qwen3.5-0.8B`重新初始化同seed语言LoRA，400个优化器步骤。初始化参数SHA必须与旧分层实验一致，不加载旧微调终点。

- 使用报告56的固定清单，已登录2,720个位置保持，登录前480个位置替换；故事组变少、桶和能力分布同时改变，不作为纯单因素实验。
- 启动前有独立25步训练探针，第12步保存并退出，再由另一个进程恢复到25步。探针不读评估题面，适配器不进入正式训练。正式训练从头开始，不能把探针当作第1—25步接着训练。
- 每轮重新测原始模型开发基线；旧分层400步作为历史参照，不重跑两臂，不参与本轮候选选择。启动前核验历史模型、环境、提示词、数据集、优化设置、结果绑定和检查点；收尾再从其归档logits重算指标与配对故事组bootstrap。
- 相同环境不等于相同GPU负载或时钟，旧、新延迟标为历史会话测量，不能把差值直接归因于模型或采样。新实验不调用Jev。

## 启动、进度、暂停与恢复

在仓库根目录使用已有`.venv-qwen35`环境；路径由脚本相对定位，缓存和产物放在工作区。

```powershell
. .\scripts\use-env.ps1

# 先运行一次探针；默认在第12步保存后退出
.\scripts\start-financial-preauth.ps1 -Probe
.\.venv-qwen35\Scripts\python.exe -m qwenlab.financial_preauth_cycle progress --probe
# 只有探针进程已退出且状态paused时才恢复
.\scripts\resume-financial-preauth.ps1 -Probe

# 探针完成、审核及所有绑定通过后，正式训练从头开始
.\scripts\start-financial-preauth.ps1
.\.venv-qwen35\Scripts\python.exe -m qwenlab.financial_preauth_cycle progress
.\.venv-qwen35\Scripts\python.exe -m qwenlab.financial_preauth_cycle progress --watch

# 需要关机时，等待命令明确确认检查点完整、进程退出和锁释放
.\scripts\pause-financial-preauth.ps1
# 次日恢复同一协议与样本游标
.\scripts\resume-financial-preauth.ps1
```

已启动或完成时不要重复执行start。探针命令适用于首次执行；本机探针完成后只需查看记录，不重跑。暂停探针可给pause加`-Probe`。进度中的分钟估算只含剩余优化器更新，不含加载、保存和评估；保存尚未确认时不要关机。

输出目录为`results/financial-preauth-probe-v1/`、`results/financial-preauth-v1/`；日志位置由`.local/financial-preauth-main-launch.json`、`.local/financial-preauth-probe-launch.json`记录。原始检查点、模型、缓存、日志和私人笔记均不上传Git。正式收尾包含`selection.json`、`historical-comparison.json`、`comparison.json`和`report.md`。

这份执行器还依赖本地旧`financial-sampling-v1`结果及分层400步检查点作对照完整性验证；只有仓库源码、没有这些产物的机器不能直接启动本实验。应先完成旧实验或获取与协议SHA匹配的归档，不应删除校验来绕过依赖。
