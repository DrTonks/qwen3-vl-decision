# V8夜间暂停与恢复

用户计划夜间关机，采用手动命令控制。没有设置23点自动停止，也不会自动关闭电脑。以下命令在`qwen`目录的PowerShell执行。

## 今晚暂停

```powershell
& .\scripts\pause-support-v8.ps1
```

命令先记录暂停意图，等待下一个完整检查点保存。当前每100步保存一次，通常需要等待0～10分钟。脚本校验模型、优化器/随机状态文件、训练协议及教师缓存，强制落盘后，仅停止本工作区的本次V8训练及其调度进程。

**看到“暂停成功……可以正常关机”后，再从Windows正常关机。**不要直接关电源，也不要在命令仍等待时把关闭终端当作暂停成功。终止进程的瞬间可能已经开始计算下一步；恢复时会从已确认保存的步数继续，少量未保存步骤会重算。

如果停电临近、不方便等下一个检查点，可以选择：

```powershell
& .\scripts\pause-support-v8.ps1 -Immediate
```

此选项从最近已完成的检查点暂停，可能重算不足100步的进度；它仍先校验与落盘，不跳过完整性检查。正常情况下使用不带参数的命令。

只想检查、不暂停：

```powershell
& .\scripts\pause-support-v8.ps1 -CheckOnly
```

## 明早恢复

开机后进入`qwen`目录：

```powershell
& .\scripts\resume-support-v8.ps1
```

它先确认没有V8进程正在运行，再核对暂停时的检查点、协议及教师缓存，然后调用原启动脚本的`-Resume`入口。加载模型和重新编码训练数据需要一些时间；已完成教师缓存直接复用，不重算6,000项，不从头训练。学习率进度、优化器、随机状态和数据顺序由原恢复逻辑继续，原验收门槛不变。

查看训练进度：

```powershell
.\.venv\Scripts\python.exe -m qwenlab.support_train_v8 progress --watch
```

查看手动暂停状态：

```powershell
.\.venv\Scripts\python.exe -m qwenlab.support_control status
```

暂停状态保存在`.local/support-v8-pause.json`。原训练进度文件可能停留在最后一条运行记录，判断是否已手动暂停应以控制命令输出和该记录为准。`paused`表示已确认退出且检查点完好；`waiting_checkpoint`表示仍在等待；`pause_failed`不能当作可以关机的确认。

定时跟进已增加暂停保护：发现暂停请求或已暂停状态时，不把它当作崩溃，不自动重新拉起训练。只有用户运行恢复命令后，才按正常流程继续跟进。

## 实现边界

`src/qwenlab/support_control.py`是外部进程控制，不改动已冻结的训练源码、数据、超参数或门槛。进程匹配同时检查模块参数、工作目录、父子树及PID创建时间；不会笼统结束所有Python进程。先停止周期调度进程，避免暂停训练时启动后续评估。

校验失败、存在重复进程树、没有完整检查点或暂停未确认完成时，脚本明确报错。训练因开发门槛失败或已经进入最终评估时，应查看实验状态，不把恢复脚本用于绕过门槛。
