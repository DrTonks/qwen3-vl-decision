# 2B完整覆盖训练与分批发布

## 目标与边界

2026-10-08：从官方 Qwen3-VL-2B-Instruct 新建 LoRA，验证完整覆盖训练能否改善金融客服八动作决策和工具选择。不是继续训练旧 V5/V8，也不是全参数微调。训练前不能承诺超过 0.8B 或 Jev。

使用与 0.8B 完整实验相同的 13,378 条训练数据、冻结顺序、两轮共 3,346 个优化步骤，每轮覆盖每条数据一次；相同学习率 5e-5、100 步预热、有效批次 8、评估门槛和早停规则。评估步骤为 500/1000/1500/1673/2000/2500/3000/3346。只有满足原门槛的候选才能进入校准和最终测试。不根据已看过的开发错题新增训练数据。

2B 使用 NF4 QLoRA、FP32 语言侧 q_proj/v_proj LoRA（rank 8）、microbatch 1、累积 8 次；视觉参数冻结，本轮仅文本验证。使用模型原生聊天模板，保留相同业务消息、动作定义和可信状态。不同模型架构、精度、模板及 microbatch 会影响结果，因此差异不能全部解释为参数规模的作用。

## 本地操作

在仓库根目录运行 PowerShell：

```powershell
# 查看实时进度（Ctrl+C 只退出观察）
.\.venv-qwen35\Scripts\python.exe -m qwenlab.financial_2b_full_coverage_cycle progress --watch
# 安全暂停：等待脚本明确确认检查点完整、进程退出后再关机
.\scripts\pause-financial-2b-full-coverage.ps1
# 次日恢复；不要重复运行新建命令
.\scripts\resume-financial-2b-full-coverage.ps1
```

新实验首次启动命令为 `./scripts/start-financial-2b-full-coverage.ps1`；已有实验拒绝覆盖。环境使用仓库 `.venv-qwen35`，模型、缓存和检查点保存在项目所在磁盘。记录位于 `results/financial-2b-full-coverage-v1/`，启动日志索引为 `.local/financial-2b-full-coverage-main-launch.json`。
