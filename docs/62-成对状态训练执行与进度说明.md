## 查看、暂停和恢复

在qwen仓库根目录打开PowerShell：

```powershell
# 查看正式运行当前阶段、步数、最近单步耗时与剩余纯训练分钟
.\.venv-qwen35\Scripts\python.exe -m qwenlab.financial_state_pair_cycle progress

# 持续查看，Ctrl+C只退出进度查看器
.\.venv-qwen35\Scripts\python.exe -m qwenlab.financial_state_pair_cycle progress --watch

# 请求安全暂停，等命令确认保存完成、工作进程退出后再关机
.\scripts\pause-financial-state-pair.ps1

# 下一次开机后从同一检查点恢复
.\scripts\resume-financial-state-pair.ps1
```

查看或控制试训时，Python进度命令加`--probe`，PowerShell暂停/恢复脚本加`-Probe`。`start-financial-state-pair.ps1 -Probe`用于首次试训，`start-financial-state-pair.ps1`用于首次正式运行；已存在运行拒绝覆盖，需要用恢复命令。完成的运行拒绝重复启动。

`safe_to_shutdown=true`只在确认暂停/完成状态、工作进程退出、检查点完整以及GPU锁释放后才返回。`progress`中的剩余分钟仅估算优化器更新，不含加载、编码、保存或评估。脚本不安装服务、不设置开机自启，也没有恢复已取消的定时任务。
