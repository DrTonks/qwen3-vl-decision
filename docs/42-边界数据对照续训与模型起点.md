# 0.8B边界数据对照续训与2B模型起点

2026-10-02。用户选择先完成Qwen3.5-0.8B，2B暂时只讨论；独立子agent复核通过后执行本轮训练。本文记录方案与执行状态，不将训练启动当作效果达标。

## 本轮解决什么问题

首轮0.8B已经完整遍历11,899条训练数据两次，开发动作准确率达到97.66%，但仍有误拒绝和人工漏判。新一轮检验：从相同适配器再训练相同预算时，加入训练来源的边界对照，是否比单纯重复旧数据更有帮助。

两个分支都从`financial-qwen35-v1/step-2976`加载语言LoRA；创建新的AdamW优化器与学习率计划，不继承首轮已经走完的优化器进度。因此这是一个新续训实验，不是中断恢复首轮，也不是从随机参数开始训练。

|起点|同一第2976步适配器|同一第2976步适配器|

两臂串行运行，避免争用显卡。等两臂所有固定开发检查点完成后再统一选型，门槛沿用首轮，绝不依据结果延长训练或放宽条件。只有合格的全局固定候选进入校准和最终集；没有合格候选就结束本预算。

按首轮平均每步3.13秒，两臂纯训练约160分钟；含加载、检查点和评估，预估170～220分钟。实际会受电脑温度、功耗与其他程序影响，应以运行中的最近步耗时估计为准。

## 数据审核发现与发布

372条候选已经由独立AI子agent逐条复核。12条存在业务契约歧义：虽然申请详情工具被移除，申请列表仍能返回用户询问的状态、金额或产品，不能直接推断必须转人工。为避免把不清楚的工具边界学成硬规则，按来源组整组隔离36条，不用开发错题改写这些行。

最终发布336条、112个来源组：clarify 48、tool 48、human 176、answer 32、refuse 32。原八动作训练池负责保留retrieve、redirect、close等能力。这336条是受控合成扩展，不等于336个独立业务场景。审核是**独立AI审核，未人工审核**。

- 原候选：`data/financial-boundary-candidates-v1/`，保持原样与待发布历史状态。
- 独立审核：`docs/evidence/financial-boundary-label-review.json`，绑定候选内容SHA并记录所有372条结论。
- 实际新增训练数据：`data/financial-boundary-training-v1/training.json`。
- 排除来源组：`data/financial-boundary-training-v1/excluded-groups.json`。
- 数据发布器：`src/qwenlab/financial_boundary_release.py`，只有原样、整组接受的候选进入新版本。

这次发现也说明“模型错误”可能混有工具说明或标注边界问题。旧开发集及其门槛保持冻结；后续另建版本时应重新审查工具可替代性，不能将本轮分数直接当成真实业务能力的完整衡量。

## 为什么0.8B续训，2B建议重新建LoRA

0.8B当前适配器已在同一八动作、同一提示与工具契约下完成完整覆盖训练，适合做小学习率的受控增量实验。继续训练是否改善仍需对照验证，不能仅凭损失下降判断。

2B的不同历史版本要分开看：

1. V5等旧四路由适配器的输出类别和训练目标不同，不建议直接当成新的金融八动作模型起点。
2. 最近八动作2B版本只有200步，采样覆盖1,175条独立训练记录，并非遍历全部11,899条；其80.47%开发准确率不能与0.8B的2,976步97.66%直接比较来判断模型大小优劣。
3. 将来正式对比2B时，建议从官方`Qwen3-VL-2B-Instruct`权重加载**全新LoRA**，固定完整覆盖的数据与预算，再评估。这里“重新训练”是重新微调适配器，保留官方预训练与指令能力；不是从零预训练2B参数。
4. 从2B八动作200步适配器继续在技术上可行，但会带入该轮不均匀采样和旧学习率历程。可以作为单独的初始化对照，不应当作保证更好的默认选择。本次不运行2B。

新数据的336条占总池约2.75%，整个实验旨在测量边界增量的价值；单独用336条训练全部八动作会遗忘其他能力。

## 评估与限制

训练只读取训练分区；开发集用于固定检查点选择，校准集只拟合温度和兜底阈值，最终集仅评价预先选定候选。已缓存的Jev开发/校准/最终预测可按原内容契约复用，无新增付费API请求。

开发集已经多次观察，且只有8个合成宏故事。即使门槛通过，也只能说明本协议表现符合要求，不能排除模板过拟合、真实用户分布偏移或图文任务退化。文本任务没有训练图像能力，工具参数、鉴权、人工接通仍属于后端责任。

默认服务、App、后端provider保持当前配置。本轮不提交、不推送、不部署，后续发布需单独决定。
