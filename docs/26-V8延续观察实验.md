## 命令

在项目根目录的PowerShell中执行：

```powershell
# 仅首次启动；已运行时不要重复执行
.\scripts\start-support-v8-observe.ps1

# 持续查看进度，Ctrl+C只退出查看
.\.venv\Scripts\python.exe -m qwenlab.support_v8_observe progress --watch

# 如需关机：请求在完整检查点后退出，等待“可以正常关机”
.\.venv\Scripts\python.exe -m qwenlab.support_v8_observe pause

# 手动恢复本次观察实验；已结束的实验不可重新启动
.\scripts\start-support-v8-observe.ps1 -Resume
```

原来的`pause-support-v8.ps1`和`resume-support-v8.ps1`只控制原V8任务，本次观察使用上面的新命令。每100步或评估点保存一次；暂停通常等待不超过约10分钟纯训练，遇到评估还需等评估阶段完成。
