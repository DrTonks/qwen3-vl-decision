# LoRA 推理开销的同进程对照

同一个已加载模型、相同输入、相同 GPU，逐请求交替禁用/启用适配器；切换开关不计时。32 条请求，每种模式各重复三次。

|模式|P50（ms）|P95（ms）|
|---|---:|---:|
|disabled|352.99|384.69|
|enabled|369.60|402.38|

启用后的相对开销：P50 +4.71%，P95 +4.60%。
按请求分组的平均额外耗时 16.38 ms，探索性 95% 区间 [14.89, 17.90] ms。
与原冻结记录比较的类别不一致次数：{'disabled': 0, 'enabled': 0}（每种模式 288 个任务预测）。
该实验隔离启用适配器分支的开销，但不等同于加载基础模型或合并权重后的部署。硬件波动不能完全消除。
没有合并 NF4 权重、修改原始测试成绩或开启新训练。
